Receipts to checked data

Which receipts can skip a person, and how sure are we?

Docket reads a receipt and stores it as clean data, but only after a strict format check. Each field also gets a confidence score, and a receipt goes to a person when any field looks doubtful.

This page runs on recorded results. Every number and every receipt below was produced earlier by a real model run and saved. Nothing here calls a model. The small model is Qwen 3.5 9B running locally; the results for Claude come from the saved Bedrock responses.
